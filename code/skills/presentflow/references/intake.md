# 材料场景与分阶段提问

| 已有材料 | 主要动作 | 应保留/确认 |
|---|---|---|
| 只有论文 PDF | 读论文，确定结构，做 PPT，写逐页稿 | 语言、时长；模板可选，品牌可用文字 |
| PDF＋模板 | 分析整份模板，生成新汇报和逐页稿 | 模板语言/视觉；新会议/作者/单位 |
| PDF＋模板＋讲稿 | 按论文验证讲稿，再按模板制片 | 讲稿对齐与篇幅，不能自动照抄错数据 |
| PDF＋成稿 PPT，无稿 | 保留排版，核对来源，按页补稿 | 原页面顺序与重点 |
| 成稿 PPT，无 PDF，无稿 | 按现有内容写稿 | 不臆造未提供的论文或数据 |
| 成稿 PPT＋部分备注 | 只补空缺和衔接 | 已有效备注不全部推倒重写 |
| PPT＋完整备注 | 核对可朗读性，按需配音 | 语言、原稿、现有品牌 |
| PPT＋外部稿 | 对齐页码；如与备注冲突则询问 | 以哪份为准 |
| PDF＋成稿 PPT＋模板 | 询问保留成稿还是重排 | 不擅自套模板覆盖成稿 |
| 只有讲稿（可带模板） | 按稿子组织 PPT | 内容依据、标题、时长；不假称有论文支持 |
| PPT＋逐页音频 | 导入装配，不再克隆 | 音频与稿子的页号、文本、哈希 |
| PPT 已带旧配音 | 询问复用、保留还是替换 | 不自动删除不属于本工具的媒体 |
| 扫描/加密 PDF、混合语言、页数冲突 | 指出具体缺口并继续独立步骤 | 不猜页码、密码、语言或数据 |

先问材料和汇报需求，再问品牌；完成内容后再询问配音与部署。用户一开始已说明配音要求时可提前并行收集硬件和隐私偏好，但不重复问。

`plan` 返回全部 `questions`、当前 `current_stage` 与最多三项 `questions_now`；前端应显示当前阶段，避免把所有录音/云服务问题一次丢给只想做 PPT 的用户。`answer --set` 记录的是用户已经表达的答案。

可把语言和时长合并问一次：“这次用什么语言，报告大约多久？”品牌合并问一次：“报告场合、会议名、报告人/单位是什么？标志上传、官网找还是只用文字？”没有硬性要求时可采用清晰写明的假设继续草稿，不能擅自授权安装/付费/上传。
