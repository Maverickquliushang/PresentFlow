# PresentFlow

Current code lives in `code/`. Project temp/cache data stays in `code/.tmp` and `code/.cache`; Python uses the independent centrally configured `presentflow` environment.

Load `project-env.ps1` in each new PowerShell process. Preserve source papers, templates, decks, recordings, and existing user work. Private task data and machine configuration must remain outside shareable source. Do not upload data or choose a paid/cloud/model deployment without the user's corresponding choice.
