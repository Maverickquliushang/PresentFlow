# 0.1.0 验证范围

在 Windows、Python 3.13 独立环境和桌面 PowerPoint 上执行；主要测试资料为合成示例，另对既有 15 页论文进行了本地只读提取。没有上传用户录音或论文，真实论文不随源码分发。

| 验证 | 结果 |
|---|---|
| 单元/契约测试 | 40 项通过；常规运行另有 1 项原生集成测试默认跳过 |
| 通用 Skill 格式 | 校验通过 |
| 只有 PDF 的入口 | 真实 15 页论文成功提取，路由至 paper_only；首先询问语言、时长、模板 |
| 可安装核心 | wheel 构建通过，包含原生脚本；核心运行不依赖个人音色或模型 |
| 新建可编辑 PPT | 原生 PowerPoint 生成 3 页，含原生表格，已查看渲染 |
| 模板替换 | 克隆真实模板页并替换所有文本，生成 2 页；支持默认形状名称本地化时通过 ID 映射 |
| 已有 PPT 仅更新备注 | 3 页逐像素相同，修改的备注与稿子一致 |
| 配音装配 | 本机 SAPI 生成测试旁白，3 页 MP3 内嵌、无宏、备注与计时匹配 |
| 实际原生播放导出 | 导出完整视频 34.72 秒，对应计划 34.564 秒；每页语音片段均有非零有效音量 |
| 网络/付费 API | 使用模拟响应验证授权先于请求、用途/数据变化失效、缓存和累计预算；没有调用真实在线账号 |
| 本地 Qwen | 适配器与缓存来自先前已实测原型，通用项目仅检查选择/配置/缓存导入边界；本次没有在新环境安装 GPU 依赖或重复运行克隆 |

CLI 不自动证明论文结论正确；AI 必须看原图、核对来源并检查完整稿子。未声称所有模板、所有系统、全部语言和云账号已经验证。原生验证的可复现入口：

```powershell
. ./project-env.ps1
$env:PRESENTFLOW_NATIVE_TESTS='1'
python -m pytest code/tests/test_native.py -q -s
```

原生测试仅在显式设置环境变量且为 Windows 时执行；需要 PowerPoint、SAPI、FFmpeg。常规测试不需要 Office、GPU、模型或在线凭据。详细运行证据留项目 output/ 和 code/.tmp/，不含进源码分发包。
